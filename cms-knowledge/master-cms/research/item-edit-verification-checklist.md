# 문항 수정 화면 실제 UI 검증 체크리스트

작성일은 2026-11-06입니다. [문항 수정 정적 동작 조사](item-edit-behavior.md)와 작성 시점에 존재한 `evidence/011~049`의 상세·수정·모달 접근성 JSON/txt, 필요한 기존 PNG를 대조했습니다. 이 문서를 작성하면서 브라우저·GUI·클립보드를 조작하거나 사이트 데이터를 변경하지 않았습니다. 이후 메인이 추가하는 증거는 해당 행의 현재 증거·검증 상태에 별도로 반영해야 합니다.

## 판정과 실행 범위

- **표시 확인**은 특정 표본의 요소·값·결과 화면을 기존 증거에서 확인했다는 뜻입니다. 편집, 검증 분기, 저장, 서버 반영까지 완료했다는 뜻은 아닙니다. 체크박스는 해당 행에 적힌 범위에만 적용합니다.
- **미검증**은 정적 근거 또는 조사 항목만 있고 실제 UI 행동 증거가 없는 상태입니다. 정적 소스의 정상 분기를 실제 화면 검증 완료로 올리지 않습니다.
- 데이터 변경 여부의 **브라우저만**은 저장하지 않은 폼·선택·미리보기 상태만 바꾸는 검사입니다. **서버 변경** 또는 새 시험 자료·실패 응답·세션 조작이 필요한 행에는 **허용된 테스트 대상 필요**를 명시했습니다. 이 문서는 해당 검사를 실행하지 않습니다.
- 기대 결과의 **코드 기준**은 현재 구현을 비교하기 위한 기준입니다. 의도적으로 데이터가 초기화되거나 잘못된 저장값이 축약되는 동작도 그대로 기록했습니다. 제품 요구사항으로 승인되었다는 뜻은 아닙니다. 서버 내부 규칙은 미확정으로 남깁니다.
- 공통 검사는 한 번 정의하고 적용 대상을 명시합니다. 모든 14개 형태에는 **F01 형태 왕복**, **R01 정상 저장값 복원**, **P01 편집 OMR 미리보기**를 적용하되, 사례별 결과는 형태 코드 단위로 따로 기록해야 합니다. 공통 검사의 한 형태 성공을 다른 형태의 성공으로 복사하지 않습니다.
- 최종 저장 확인 버튼은 저장 승인 행에서만 누릅니다. 그 외 전체 반영 검사는 필수·편집기·OMR 검증 결과 또는 확인창 노출까지만 확인하고 취소합니다.

## 결과 기록 규칙

실행 후 각 행에 날짜·문항/상세ID·형태코드·진입 draft 상태·행동 전후 증거 파일·실제 결과를 남깁니다. F01/R01/P01은 형태 코드 14개를 개별로 추적합니다. 정상·빈값·경계 중 일부만 확인했으면 전체 행을 완료로 바꾸지 않고 확인한 하위 범위를 상태에 적습니다. 저장 검사에서는 토큰·인증 쿠키·presigned URL 전체를 기록하지 않습니다. 서버 기준이 미확정인 행은 관찰 결과와 합의된 기준을 함께 확보한 뒤 통과 여부를 정합니다.

이 파일의 초기 완료 범위는 A01·A02·A03·Q01의 **기존 표본 표시/결과 화면 확인**뿐입니다. 다른 행은 정적 근거 또는 일부 표시만 있어 실제 UI 검증이 남아 있습니다.
