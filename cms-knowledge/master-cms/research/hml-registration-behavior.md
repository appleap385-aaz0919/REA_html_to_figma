# HML 신규 등록·처리 상세 화면의 동작 조사

2026-11-06에 확보한 HML 신규 등록·문서 628 승인 상세·문서 595 파일 오류 실패 상세·문서 369 초안 상세 원본과 실제 선언된 공통·Dropzone·자동완성·문항 뷰어 코드를 정적으로 분석했습니다. 기존 GUI 증거 180~193·203~205·214~215·227~234·239~246을 표시와 제한된 입력 동작에 대조했습니다. 214와 215는 중복이며, 227 이후의 잘린 AX·242의 미도달 스크롤·243의 잘못된 클릭은 해당 기능 완료 근거로 세지 않았습니다. 이 연구에서는 GUI·브라우저·클립보드를 제어하지 않았고, CMS 업무 API·파일 업로드·등록·삭제를 실행하지 않았습니다.
