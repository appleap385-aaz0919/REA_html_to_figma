# HTML 문항 편집기 동작 조사

2026-11-06에 CMS가 선언한 `DongaQuestionEditor` vendor 원본과 부모 연동 코드를 정적으로 분석했습니다. 기존 evidence/083~098은 표시·결과 화면의 범위를 확인하는 데만 사용했습니다. 브라우저·GUI·클립보드를 조작하지 않았고, 다운로드한 JavaScript를 실행하거나 CMS 저장·업로드 요청을 하지 않았습니다.

## 1. 원본 보존과 직접 참조 리소스

schema와 실제 HTML에 선언된 원본은 `/js/vendor/donga-question-editor/donga-question-editor.min-2da16fddbc2dd1522ca1b7947ea73f1e.js`입니다. 공개 GET은 요청 URL 그대로 HTTP 200, `text/javascript;charset=UTF-8`, 2,696,938바이트를 반환했으며 로그인 HTML이 아니었습니다. 원본 SHA-256은 `1e774fb0b47d4190781338ca943e40d93ea93cfffed92f7558c38f93e0fc5b51`입니다.
