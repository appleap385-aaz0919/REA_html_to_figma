수식 입력기 데모

KaTeX + MathLive + TinyMCE 통합 검증 페이지 (서버사이드 이식본)

1. 하이브리드 에디터 (텍스트 + 수식)

툴바의 "초등 수식"/"일반 수식" 버튼으로 레벨별 전용 키보드가 뜨고, 삽입된 수식 클릭으로 수정. 다이얼로그의 "손글씨" 탭에서 수식을 그려 OCR 인식 가능.

이차방정식의 근의 공식을 수식 버튼으로 삽입해 보세요.

에디터 내 수식 (LaTeX 값 ↔ 실제 KaTeX 값)

에디터에 삽입된 수식이 없습니다.

왼쪽 "LaTeX 값"은 저장·비교용 LaTeX 소스, 오른쪽은 그 값을 KaTeX 로 렌더한 결과입니다.

저장될 HTML 출력 
<p>이차방정식의 근의 공식을 수식 버튼으로 삽입해 보세요.</p>

읽기전용 렌더 (해설·미리보기용)

이차방정식의 근의 공식을 수식 버튼으로 삽입해 보세요.

2. 수식 단독 답안 입력

칸에 바로 입력하거나, Σ 버튼으로 수식입력기(고등 키패드)를 엽니다.

placeholder(LaTeX):

Σ

필드를 모두 지우면 placeholder 가 보입니다. 스페이스바 또는 키패드 알파벳 탭의 스페이스 키로 공백이 삽입됩니다.

LaTeX 출력: x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}

3. 렌더 전용 (KaTeX)

위 답안 입력값을 KaTeX 블록 수식으로 실시간 렌더:

x=−b±b2−4ac2ax=\frac{-b\pm\sqrt{b^2-4ac}}{2a}x=2a−b±b2−4ac​​

4. 실제 문제 데이터 로드 → 수식 편집 → HTML 변화 확인

샘플 문제(samples.json)의 블록을 선택하면 원본 text 가 입력란에 채워집니다. "변환 + 로드"를 누르면 $...$ 수식이 편집 가능한 수식 노드로 변환되어 에디터에 로드됩니다. 수식을 클릭해 수정하면 아래 "③ 편집 후 출력 HTML"이 실시간으로 바뀝니다.

x−3,x,x+3x-3, x, x+3x−3,x,x+3은 변의 길이이므로 x>3⋯⋯㉠x\gt 3\quad\cdots\cdots ㉠x>3⋯⋯㉠
세 변 중 가장 긴 변의 길이는 x+3x+3x+3이므로
x+3<(x−3)+x, x>6⋯⋯㉡x+3<(x-3)+x ,~ x>6\quad\cdots\cdots ㉡x+3<(x−3)+x, x>6⋯⋯㉡
이 삼각형이 예각삼각형이 되려면
(x+3)2<x2+(x−3)2,x2−12x>0(x+3)^{2}\lt x^{2}+(x-3)^{2}, x^{2}-12 x \gt 0(x+3)2<x2+(x−3)2,x2−12x>0
x(x−12)>0, x<0x(x-12)\gt 0 ,~ x<0x(x−12)>0, x<0 또는 x>12⋯⋯㉢x\gt 12\quad\cdots\cdots㉢x>12⋯⋯㉢
㉠,㉡,㉢의 공통부분을 구하면


x>12x\gt 12x>12
따라서 자연수 xxx의 최솟값은 131313이다.
