기존 파일을 처음으로 Git에 보관한 저장소입니다. 과거 작업의 시점과 내용은 원래 세션 기록과 근거 파일에 남아 있으며, 과거 날짜의 Git 커밋을 새로 만들지 않습니다.

로컬 커밋은 클라우드 백업과 다릅니다. Figma 파일은 Figma에 저장되어 있고, 이 저장소에는 작업 스크립트·계획·근거·검증 캡처와 해당 노드 링크가 들어 있습니다.
