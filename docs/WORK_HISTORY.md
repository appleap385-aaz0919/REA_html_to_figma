## 2026-11-12: HML 50문항 초과 평가지 등록 제한 반영

사용자 첨부 요청을 기존 Master CMS 스토리보드에 반영했습니다. [변경 예정 부분 화면](https://www.figma.com/design/xCjdhdFkSbToMiRVlXVN2V/?node-id=13-2)을 초안 검수 섹션에 추가하고 신규 등록·초안 검수·승인 결과 3개 화면의 설명 4개를 수정했습니다. 실제 CMS에는 앞으로 반영될 정책이며 이번 작업에서 CMS 서버 데이터는 변경하지 않았습니다.

- 한 HML 파일의 문항 수가 **50을 초과하면** 평가지 등록여부를 미등록(N)으로 선택하고 제어를 비활성화합니다. `* 50문항이 넘는 HML은 평가지로 등록할 수 없습니다.`를 표시합니다.
- HML 업로드·문항 등록은 허용합니다. 기존 검수 조건을 충족하면 HML 승인도 진행하되 평가지 생성은 제한합니다. 서버 제한은 구현 요구사항이며 현재 실행 검증 결과가 아닙니다.
- 기존 초과 평가지 **31개**는 사용자 첨부에 기록된 건수입니다. DB를 재조회하거나 정리 작업을 실행하지 않았습니다. 정리 범위는 평가지 정보이며 원본 HML과 문항은 유지합니다. HML 문서 전체 폐기 기능으로 처리하지 않습니다.
- 요청 첫 문장에는 ‘50문항 이상’, 상세 지시와 안내에는 ‘50문항 초과’가 혼재합니다. 상세 지시를 기준으로 51문항부터 제한하는 설계를 반영했으며 **정확히 50문항의 기준**은 구현 전에 확인해야 합니다. 세트 자식 포함과 삭제·실패 문항 제외 여부도 요청에서 확정되지 않았습니다.

정책 원본과 근거는 `design-specs/hml-paper-limit-policy.json`, 검증은 `design-specs/hml-paper-limit-verification.json`에 있습니다. 실제 Figma 공개 플러그인 API로 변경 3개 화면과 신규 부분 화면을 읽어 텍스트 프레임 이탈·겹침·문자 깨짐이 모두 0건임을 확인하고 화면 캡처를 검토했습니다. 최신 delivery JSON에도 이번 변경을 연결했습니다. Figma Scripter는 닫고 브라우저 연결을 종료했습니다.
