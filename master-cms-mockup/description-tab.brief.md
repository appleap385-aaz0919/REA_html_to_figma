HTML은 직접 파일로 열며 백엔드와 네트워크 없이 정적 설명을 읽습니다. Figma 반영 완료 시 같은 내보내기에서 정적 JS와 연결 폴더 JSON을 생성합니다. 연결된 패널은 설명 변경만 반영하며 서비스 데이터·검수 이력·사용자 승인을 변경하지 않습니다. 원격 Figma 수동 편집을 계속 감시하는 기능은 포함하지 않습니다.
