# 로컬 목업 검수 범위

이 폴더의 file:// 정적 산출물만 검수합니다. 실제 CMS, 기존 사용자 Chrome 프로필과 다른 프로젝트는 조작하지 않습니다. 별도 테스트 브라우저와 임시 저장소만 사용합니다.

- 프로필: CRUD 앱. 기존 Playwright 검사 도구를 확장합니다.
- 정책별 시드: 1103, 2207, 3301, 4409. 정책 RNG는 Python Random(MT19937)이며 앱 데이터는 고정 예시입니다.
- 정책: 신규 사용자, 연속 클릭, 임시저장 재실행, 화면 이탈, 화면 크기 변경, 느린 조작, 임의 탐색, 긴 한국어 입력, 동작 줄이기, 두 탭 동시 편집입니다.
- 각 시드·정책을 같은 최종 코드에서 두 번 실행합니다. 기능 회귀 검사 32개와 별도로 수행합니다. 최대 20분, 사례별 180초, 동작별 15초, 증거 최대 250MB입니다. 정책별 시드 수는 목업용으로 4개를 선택했습니다.
- 관측은 각 동작 직전·직후입니다. 프레임마다 검사하거나 실제 모바일 OS·키보드를 재현하지 않습니다.
- O-1~O-8: 런타임 오류, 활성 동작 수락, 화면 준비, 클릭 위치, ID·연결 무결성, 시드 재실행 결과, 처리 진행, 저장 왕복을 검사합니다. O-10은 실제 UI의 입력 반려·보존을 확인합니다.
- O-9 계정 격리는 해당하지 않습니다. 실제 인증·다중 계정 기능을 제공하지 않습니다. 두 탭 저장 충돌은 별도로 검사합니다.
- 서버 응답 순서·실제 AI 시간·세션 만료·서비스 채점·실제 한국어 IME 조합 입력은 미검증 범위입니다. 한국어 문자열 입력은 검사하지만 OS IME 검증이라고 주장하지 않습니다.
- 실패 시 최초 로그·상태·저장 데이터·스크린샷·trace를 보존합니다. 이전 실패 자료는 삭제하지 않습니다. 전체 검증 결과를 실제 CMS의 정책·기능 전체에 대한 무결성 보장으로 확대하지 않습니다.
