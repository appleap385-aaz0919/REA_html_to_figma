# 화면 재현 기준

모드는 Operate입니다. 사용자는 2026-11-13 기존 CMS 화면을 충실히 재현하도록 선택했습니다. 새 시각 체계를 만들지 않습니다.

확인한 참조는 `../design-specs/revision-captures/item-meta.png`, `../design-specs/revision-captures/hml-review.png`와 기존 화면별 계획입니다. 파란색 세로 메뉴, 흰 상단 바, 회색 섹션 제목, 얇은 테두리, 우측 검색·저장 버튼, 데이터 표와 두 열 문항 뷰어를 유지합니다. 예시 문항의 내용과 ID는 새로 만듭니다. 외부 폰트·아이콘·이미지를 내려받지 않으며 SVG 아이콘과 예시 도형을 직접 작성합니다.

화면 구조와 주요 동작을 재현합니다. 실제 HML 편집기의 엔진, 정상 HML/ZIP 파서, AI, 서비스 서버는 포함하지 않습니다. 실제 CMS의 알려진 입력 유실·숨은 서버 오류는 재현하지 않고 목업의 상태 보호를 적용합니다.
