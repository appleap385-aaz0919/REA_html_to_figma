# 화면 검수 패널 구현 기준

모드는 Operate입니다. 기존 Master CMS의 시각 체계와 업무 기능을 유지하는 국소 확장입니다.

사용자가 2026-11-19 제공한 이미지가 구상의 기준입니다. 사본은 `verification/review/reference-concept.png`입니다. 이미지에는 기존 디피니션 상세 화면, 우측 번호별 접기 카드, 빨간 영역 표시, 화면 하단의 펜 토글, 요청·수정·검수 완료 후 Figma와 기록 문서 반영 흐름이 있습니다. 사용자 제공 검토 자료로 사용하며 원본 UI를 새 디자인으로 교체하지 않습니다.

구현에서는 기존 파란색 버튼·얇은 회색 테두리·Windows 맑은 고딕을 사용합니다. 우측 380px 패널과 빨간 번호를 대응시키고, 패널을 닫으면 기존 배치로 복귀합니다. 작은 화면의 영역 지정 중에는 패널을 하단 도구 영역으로 줄입니다. 실제 CMS 기능을 검토 중이라는 사실과 에이전트 작업/사용자 검수/후속 반영 상태가 분명해야 합니다.

DOM 캡처는 참고 이미지로 명시하고 실제 캡처를 첨부할 수 있게 합니다. Figma·정책 완료는 외부 작업의 근거 기록이며 자동 수행으로 표현하지 않습니다. 서버 없는 환경에서 에이전트 연결은 작업 JSON과 결과 JSON으로 왕복합니다. 기존 DESIGN.md의 화면 재현 기준은 바꾸지 않습니다.

자동 캡처 라이브러리는 html2canvas 1.4.1이며 `vendor/html2canvas/provenance.json`과 MIT LICENSE를 함께 보존합니다. 런타임에 외부 CDN이나 서버로 요청하지 않습니다.


## 사용자 피드백에 따른 단순화

사용자는 기능 수정도 분류해야 하며 HTML·Figma·정책 반영은 에이전트가 맡아야 한다고 명확히 했습니다. 오른쪽 패널이 복잡하고 불필요한 입력이 많다는 지적에 따라 기본 흐름을 수정할 내용→작업 결과→확인 완료/재수정으로 줄였습니다. 캡처 보완·상세 기록·JSON 보관은 선택 메뉴로 옮겼습니다. 기능 수정은 관련 정책 검토 대상으로 연결합니다.

자동 전달은 서버 없이 Orca의 기존 브라우저/대화와 Python 파일 연결 프로그램으로 수행합니다. 외부 브라우저의 로컬 저장소와 구분하고 실제 전달 접수·작업 시작·결과·사용자 확인·문서 반영 상태를 혼동하지 않습니다. 새로운 시각 체계는 만들지 않았습니다.


## 일반 HTML 사용 확인 후 수정

사용자는 외부 Chrome에서 file:// HTML을 직접 봅니다. 자동 전달은 폴더 권한을 통해 같은 브라우저의 JSON을 읽고 결과를 돌려줍니다. Orca 브라우저를 사용자 화면으로 간주하지 않습니다. 사용자가 기존 기록 삭제를 요청하여 이전 검수 키와 작업 파일을 초기화했습니다. 화면 이미지 보완·첨부 입력은 제거하고, 저장된 이미지는 화면 내 확대 창에서 엽니다. 영역 다시 그리기는 같은 요청을 유지하며 즉시 다시 지정합니다. 기존 CMS의 파랑·회색·맑은 고딕을 유지합니다.


## 복수 변경 구분과 정책 결과

화면·배치/기능/오류 수정은 동시에 체크할 수 있습니다. 정책 수정은 사용자 선택에서 제외합니다. 정책 영향은 에이전트가 실제 수정 내용을 보고 판단하며 변경이 있는 경우에만 작업 결과 다음에 이전·변경 기준과 적용 조건을 표시합니다. 사용자 확인 후 문서에 반영하는 순서는 유지합니다.


## 요청 #1 및 후속 검수 UX

실제 상태 정보 수정 요청은 폐기 상태 잠금을 확인 질문으로 확정했습니다. 질문과 답변을 카드 본문에 표시하고, 결과 수신 시 수동 새로고침 안내를 지속적으로 띄웁니다. 사용자 승인은 HTML 다음 단계이며, Figma 화면·Description과 CMS 정책 문서는 승인 후 반영합니다. 파일 읽기 경합은 내부에서 재시도하며 영문 오류를 점멸하지 않습니다.


## 패널 유지와 전송된 내용

서비스 저장은 서비스 영역만 갱신합니다. 코드 새로고침 후에는 패널 열림·펼친 요청·상세 보기·스크롤·미전송 입력을 복원합니다. 화면 이동으로 패널을 닫지 않고 명시적으로 닫은 선택을 기억합니다. 추가 요청과 재수정은 카드 본문에 남기고 전송한 편집란은 비웁니다. 기존 버전의 중복 잔여 입력도 제거하되 미전송 내용은 보존합니다. 사용자 승인 이후에만 Figma 화면·Description과 CMS 정책 문서를 수정합니다.
