# Master CMS 목업 검수 보고서

2026-11-17 미리보기·전체 페이지 재검수: 이전 기능 검사에서는 화면 배치·단원 트리 재열기 검수가 부족했습니다. 사용자 지적 후 검색 폼과 표·상세·수정·등록·랩을 수정했습니다. [전체 대조 기록](FIDELITY_REPORT.md)과 [원본·목업 비교](화면_대조.html)를 함께 확인하세요. 외부 한글 편집기를 포함한 전체 UI가 실제 CMS와 동일하다는 판정은 하지 않습니다.

## 검수 대상과 실행 방식

이 폴더의 `index.html`과 로컬 CSS·JavaScript를 Chrome의 별도 테스트 프로필에서 `file://`로 직접 열었습니다. 목업 컨텍스트는 오프라인 모드를 강제했습니다. 원본 대조만 별도 온라인 컨텍스트에서 실제 개발계 미리보기를 열어 예시 JSON으로 확인했으며, 원본 문서 저장·채점 API 호출은 하지 않았습니다. 정상 실행 파일에 테스트용 변형 코드를 주입하지 않았습니다. 데이터 확인에는 읽기 전용 관측을 사용하고 저장·선택·이동은 실제 화면의 버튼과 입력 요소로 수행했습니다.

기준은 `../design-specs/revision-aligned-plan.json`, `../design-specs/revision-modal-plan.json`, `../design-specs/hml-paper-limit-policy.json`과 보존된 실제 화면입니다. **30개 화면·52개 모달의 구현 위치 대조**는 `coverage.json`에 있습니다. 이 대응표와 실행 검증은 별개이며 모든 변형의 픽셀 일치를 주장하지 않습니다.

|---|---|

## 반복 검수 방식

신규 사용자, 연속 클릭, 임시저장 재실행, 화면 이탈·뒤로가기, 화면 크기 변경, 느린 조작, 임의 탐색, 긴 한국어 문자열, 동작 줄이기, 두 탭 동시 편집을 실행합니다. 각 정책의 시드는 **1103·2207·3301·4409**이며 동일한 최종 코드에서 두 번 실행합니다.

각 동작 전후에 활성 여부·클릭 위치·화면 준비·런타임 오류·ID 중복·출처 연결·평가지 그룹 무결성과 처리 진행을 확인합니다. 재실행 시 시각·버전 번호를 제외한 논리 데이터 해시를 비교합니다. 임시저장 재실행은 테스트용 Chrome을 닫고 같은 임시 프로필로 다시 여는 실제 콜드 시작을 포함합니다.

검사기가 의도한 실패를 보고하는지도 `--oracle-self-test`로 확인했습니다. 9개 검사 ID의 고의 실패가 증거를 남기고 **예상된 종료 코드 1**을 반환했습니다. 이는 제품 검사의 실패 수에 포함하지 않습니다.

## 한계와 실제 CMS와 다른 부분

- HML/ZIP 실제 해석, 벤더 HML 엔진, AI·배포 수신·캐시 서버·필기 인식·실제 서비스 채점은 모의 처리입니다.
- 정상 디피니션 세트 ZIP과 실제 해석 HML 저장은 기존 조사에서도 확인하지 못한 범위이므로 정상 구현을 검증했다고 주장하지 않습니다.
- HTML 편집/뷰어와 OMR 편집 카드·원본 JSON의 직렬화/복원은 보존된 원본 코드를 사용합니다. 랩 수식 데모·OMR Σ 진입창은 부분 MathML 구현이고, 서비스 OMR 응답 화면과 수식 키패드는 원본 컴포넌트입니다. 서비스 수식 채점·필기 인식 API는 포함하지 않았습니다.
- 실제 CMS에서 발견한 입력 유실·숨은 서버 오류·오래된 폼 덮어쓰기는 재현하지 않았습니다. 입력 보존과 충돌 방지를 적용한 의도적인 차이입니다.
- 역할별 권한·전체 쌍둥이 생성 자격·서버 오류 분기의 실제 규칙은 미확정이며 예시 범위에서 모의 처리합니다.
