## 실제로 수행한 확인

- 원본과 동일한 1800/2200px 창 너비에서 30개 진입점의 전체 페이지를 캡처했습니다. 1280/760/390px에서는 30개 진입점 전부의 문서 너비 초과 여부를 검사했습니다. 넓은 표는 표 영역 내부에서 가로 스크롤합니다.
- 원본 공통 프레임(사이드바 256px·본문 x=272px)과 전체 문항 트리 시작 좌표를 저장된 DOM 좌표와 비교했습니다. 전체 문항 첫 필터 행의 7개 요소가 한 줄에 있는지도 검사했습니다.
- 단원 트리 접기/열기 3회, 미조회 검색 입력 유지·결과 미변경, 전체/개별 상태 체크박스·등록일 범위 조회, 메뉴 재열기, HML 문제·해답 동시 표시를 확인했습니다.
- HTML 5개 입력 구역의 개별 편집·미리보기·임시저장, OMR 선택지 추가·수정·삭제·인덱스 이동·저장, 갤러리 그룹별 닫기를 실행했습니다.
- 52개 모달 항목의 대표 상태를 실제 UI로 열었습니다. 51개 DOM 입력 영역(원본 HTML 편집기의 팝오버 포함)은 전체 화면을 캡처했습니다. 일반 모달은 Escape, 원본 팝오버는 해당 취소·닫기 동작으로 확인했습니다. 이미지 URL은 원본과 같은 native prompt이며 이벤트·기본값·취소를 기록했습니다. 모든 변형 71개의 픽셀 일치를 검사한 것은 아닙니다.

## 남는 차이와 재현 한계

- 별도 한글 편집기는 원본의 별도 창·리본·HML 엔진을 재현하지 않았습니다. 텍스트 편집과 CMS 반영 대기 흐름을 모달로 제공합니다.
- 날짜 범위의 닫힌 입력 영역과 빠른 기간은 맞췄지만, 열린 선택기는 원본 Litepicker 달력과 다릅니다. 시작/종료 날짜 입력으로 선택합니다.
- HTML 편집/뷰어와 OMR 편집 카드·직렬화·복원은 보존된 원본 코드를 실행합니다. OMR 응답 미리보기는 원본 서비스의 Vue 컴포넌트·표·답란·수식 키패드를 로컬 iframe에서 실행합니다. 서비스 채점 API와 필기 인식 API는 연결하지 않았습니다. 랩 수식 데모와 Σ 진입 팝업은 기존 부분 MathML 구현이 남아 있습니다. 원본 HTML 편집기의 수식 팝오버는 원본 번들입니다.
- 문항 내용·개수·행 높이는 예시 데이터와 실제 데이터 차이의 영향을 받습니다. 전체 문서에 표시되는 대표 문항은 최대 12개입니다.
- 서버 변환·AI·배포·관리자 명령·실제 사용자 인증은 모의 처리입니다. 개발계·서비스 CMS에 요청하지 않았습니다.

## 2026-11-16 세부 재대조에서 수정한 오류

- 문항 상세에서 HML 문제/해답을 탭으로 나눈 것이 원본과 달랐습니다. 둘을 동시에 표시하도록 수정했습니다.
- OMR 유형별로 유사 정답·범례·SET·연결·순서 고정·수동 채점 영역이 생략되어 있었습니다. 보존된 원본 14개 카드로 교체했습니다.
- 삭제 버튼이 원본 이벤트에서 제거된 뒤에는 부모 폼을 찾지 못해 저장값이 갱신되지 않았습니다. 이벤트 캡처 시 폼을 보관하고 삭제 이후 직렬화하도록 수정했습니다.
- 원본 HTML 계약에 맞지 않는 선택지 태그 때문에 선택지가 하나로 합쳐졌습니다. d-choicewrapper/li.d-choice/d-choicecount 구조로 수정했습니다.
- 원본 content의 correctHtml/gradingCriteriaHtml을 로컬 필드에 연결하고, 초기 마운트가 미저장 변경으로 잘못 기록되지 않게 했습니다.
- OMR 미리보기는 편집된 원본 JSON을 원본 서비스 컴포넌트로 전달합니다. 상세 화면과 수정·갤러리 모두 같은 로컬 iframe을 사용합니다.

[OMR 14유형 원본 대조](OMR_유형_대조.html)는 편집 카드만 같은 너비로 보여 줍니다. 14개 카드의 외곽 높이는 원본과 동일하거나 1px 이내입니다. 이는 모든 내부 픽셀이나 모든 조합의 동일성을 뜻하지 않습니다. 원본·로컬 파일의 출처와 변경 지점은 vendor/provenance.json에 있습니다.

## 2026-11-17 OMR 미리보기 팝업과 다른 팝업 재검수

이전 14유형 편집 카드 검증은 미리보기 팝업의 동일성 검증이 아니었습니다. 기존 일반 입력 폼을 제거하고 보존된 개발계 서비스의 omr-preview, ExamOmrTable, ExamAnswerControl, MathAnswerField, Select와 Vue 런타임을 묶어 실행합니다. 라우터·서버 요청만 로컬 어댑터로 바꿨습니다.

- OMR 표 머리글·번호·유형별 답란, 정답 보기 스위치, 원본 수식 키패드·연결 답란·추가 버튼, 내부 채점 버튼과 닫기 전용 footer를 반영했습니다.
- 별도 온라인 Chrome에서 실제 개발계 `/omr-preview`에 같은 예시 JSON을 전달했습니다. 14개 기본 응답 화면의 캡처 픽셀 차이는 0이며 정답 보기 14개 상태도 캡처·대조했습니다. 이는 이번 샘플의 응답 영역에 대한 결과이며 전체 CMS·모든 조합의 픽셀 동일성을 뜻하지 않습니다.
- 정답/오답·미입력·결과 초기화·재열기, O/X 세트, 복수 응답, 선택형·연결형, 수식 입력/취소·키패드 분류, 수동 채점 안내를 실행했습니다.
